# 马克思主义哲学知识库

本目录用于持续整理马克思主义哲学（简称“马哲”）的基础概念、知识框架、经典著作阅读笔记和实践案例。

> 学习原则：先理解概念，再梳理关系；区分原著观点、教材归纳和个人理解；结合具体问题检验理解。

## 一、总体知识框架

```text
马克思主义哲学
├── 1. 辩证唯物论：世界的物质性、意识的能动作用、尊重客观规律
├── 2. 唯物辩证法：联系、发展、矛盾、辩证否定
├── 3. 认识论：实践与认识、真理、认识的发展过程
└── 4. 历史唯物主义：社会存在与社会意识、社会基本矛盾、人民群众、人的价值
```

以上四部分是便于入门学习的知识组织方式，并不是将马克思主义哲学划分成彼此孤立的四种理论。

## 二、四个核心问题

| 模块 | 首先回答的问题 | 关键词 |
| --- | --- | --- |
| 辩证唯物论 | 世界的本原是什么？意识与物质是什么关系？ | 物质、意识、规律、实事求是 |
| 唯物辩证法 | 事物怎样相互联系、变化与发展？ | 联系、发展、矛盾、量变质变 |
| 认识论 | 人怎样形成、检验和发展认识？ | 实践、认识、真理 |
| 历史唯物主义 | 人类社会的发展有哪些基本规律？ | 社会存在、生产力、生产关系、人民群众 |

## 三、建议学习顺序

1. **哲学入门**：认识哲学的基本问题，区分唯物主义与唯心主义、辩证法与形而上学。
2. **辩证唯物论**：理解物质与意识、客观规律和主观能动性的关系。
3. **唯物辩证法**：重点学习联系观、发展观、矛盾分析法和辩证否定。
4. **认识论**：理解实践在认识中的作用，以及真理的客观性和具体条件。
5. **历史唯物主义**：学习社会基本矛盾、社会发展、人民群众与价值观。
6. **综合应用**：使用这些概念分析具体问题，同时检查观点的依据和适用边界。

## 四、后续知识整理计划

- 基础概念：哲学、物质、意识、实践、认识、矛盾、真理。
- 专题笔记：唯物论、辩证法、认识论、历史唯物主义。
- 易混概念：主要矛盾与矛盾的主要方面；量变与质变；唯物主义与辩证法。
- 经典阅读：《实践论》《矛盾论》等的要点、问题与个人笔记。
- 案例分析：用现实问题说明原理，并区分事实、解释与价值判断。

## 五、内容记录规范

每篇笔记尽量按照 **问题 → 核心结论 → 概念解释 → 具体案例 → 适用边界 → 参考来源** 组织，优先做到准确、可理解、可追溯。
